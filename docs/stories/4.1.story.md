# Story 4.1: Offline Detection (MVP)

## Status
Draft

## Story
**As a** mobile user,  
**I want** to know when I'm offline,  
**So that** I understand why certain features might not work immediately

## Acceptance Criteria
1. Detect network connectivity changes
2. Show offline indicator when no connection
3. Hide indicator when back online
4. Check connectivity on app foreground
5. Update UI within 1 second
6. Don't block user actions when offline

### Implementation
```typescript
import NetInfo from '@react-native-community/netinfo';

// Network hook
export const useNetworkStatus = () => {
  const [isOnline, setIsOnline] = useState(true);
  
  useEffect(() => {
    const unsubscribe = NetInfo.addEventListener(state => {
      setIsOnline(state.isConnected ?? false);
    });
    
    return unsubscribe;
  }, []);
  
  return isOnline;
};

// Offline banner
export const OfflineBanner = () => {
  const isOnline = useNetworkStatus();
  
  if (isOnline) return null;
  
  return (
    <View className="bg-orange-500 px-4 py-2">
      <Text className="text-white text-center">
        You're offline
      </Text>
    </View>
  );
};
```
