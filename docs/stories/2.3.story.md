# Story 2.3: Session Management (MVP)

## Status
Draft

## Story
**As a** mobile app user,  
**I want** my login to persist between app launches,  
**So that** I don't have to sign in every time

## Acceptance Criteria
1. Session persists after app restart
2. Auto-refresh expired tokens
3. Logout clears all session data
4. Auth state available globally
5. Loading screen while checking auth
6. Redirect to sign in if session invalid

### Session Flow
```typescript
// On app launch
const { data: { session } } = await supabase.auth.getSession();

// Listen for auth changes
supabase.auth.onAuthStateChange((event, session) => {
  if (event === 'SIGNED_IN') {
    // Store session
    storage.set('auth_session', JSON.stringify(session));
  } else if (event === 'SIGNED_OUT') {
    // Clear session
    storage.delete('auth_session');
  }
});

// Auto refresh
supabase.auth.startAutoRefresh();
```

### Protected Routes
```typescript
// In _layout.tsx
export default function RootLayout() {
  const { session, loading } = useAuth();
  
  if (loading) return <SplashScreen />;
  if (!session) return <Redirect href="/(auth)/sign-in" />;
  
  return <Tabs />;
}
```
