# Story 2.1: Email Authentication (MVP)

## Status
Draft

## Story
**As a** new user,  
**I want** to sign up and sign in with my email,  
**So that** I can create an account and access my trips securely

## Acceptance Criteria
1. Sign up screen with email/password fields
2. Email validation (proper format)
3. Password requirements (min 8 chars)
4. Email verification sent via Supabase
5. Sign in screen with email/password
6. Error messages for invalid credentials
7. Loading states during auth operations
8. Navigate to home tab after successful auth

### Supabase Auth Setup
```typescript
// Sign up
const { data, error } = await supabase.auth.signUp({
  email: 'user@example.com',
  password: 'password123',
});

// Sign in
const { data, error } = await supabase.auth.signInWithPassword({
  email: 'user@example.com',
  password: 'password123',
});
```

### Validation Rules
- Email: Valid email format
- Password: Minimum 8 characters
- Show requirements below password field
