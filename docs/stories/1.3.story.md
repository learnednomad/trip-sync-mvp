# Story 1.3: Basic Navigation Setup (MVP)

## Status
Ready for Review

## Story
**As a** mobile app user,  
**I want** simple navigation between app screens,  
**So that** I can access my dashboard, trips, explore content, and settings easily

## Acceptance Criteria
1. Tab navigation with 4 tabs: Home, Trips, Explore, Settings
2. Stack navigation within each tab
3. Navigation works with Expo Router file structure
4. Basic header with title
5. Tab icons (simple, no custom icons)
6. Navigation state persists correctly

- Explore: "Coming soon" message
- Settings: Basic menu items

### MVP Navigation Structure
```
app/
├── _layout.tsx           # Root layout
├── (auth)/              # Auth group (future)
├── (tabs)/              # Tab group
│   ├── _layout.tsx      # Tab layout
│   ├── home/
│   │   ├── index.tsx    # Home dashboard
│   │   └── notifications.tsx # Notifications
│   ├── trips/
│   │   ├── index.tsx    # Trip list
│   │   ├── [id].tsx     # Trip detail
│   │   └── [id]/expenses.tsx # Trip expenses
│   ├── explore/
│   │   ├── index.tsx    # Explore/discover
│   │   └── [id].tsx     # Public trip detail
│   └── settings/
│       ├── index.tsx    # Settings main
│       └── profile.tsx  # Profile screen
└── +not-found.tsx       # 404 screen
```

### Simplifications
- NO deep linking
- NO custom transitions
- NO drawer navigation
- NO complex gestures
- Use default Expo Router behavior
