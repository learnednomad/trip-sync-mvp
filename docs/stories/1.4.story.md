### State Architecture (Simple!)
```
/src/
├── store/
│   ├── auth.ts         # Zustand auth store
│   └── index.ts        # Store exports
├── lib/
│   ├── supabase.ts     # Client & helpers
│   ├── storage.ts      # MMKV utilities
│   └── query-client.ts # TanStack setup
└── providers/
    └── app-providers.tsx # All providers
```

### MVP State Approach
- NO complex persistence
- NO state migrations  
- NO advanced caching
- NO optimistic updates (yet)
- Focus on WORKING basics
