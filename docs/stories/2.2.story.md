# Story 2.2: Apple Sign In (MVP)

## Status
Draft

## Story
**As an** iOS user,  
**I want** to sign in with my Apple ID,  
**So that** I can quickly create an account without another password

## Acceptance Criteria
1. "Sign in with Apple" button on auth screens
2. Native Apple authentication flow
3. Handle successful authentication
4. Link Apple account to email if same
5. Create user profile with Apple data
6. Only show on iOS devices
7. Graceful fallback on Android

## Dev Notes

### Dependencies
- **Story 2.1**: Base auth flow must exist
- **External**: Apple Developer account configured
- **External**: Bundle ID registered with Sign in with Apple

### Implementation
```typescript
import * as AppleAuthentication from 'expo-apple-authentication';

// Check availability
const isAvailable = await AppleAuthentication.isAvailableAsync();

// Sign in
const credential = await AppleAuthentication.signInAsync({
  requestedScopes: [
    AppleAuthentication.AppleAuthenticationScope.FULL_NAME,
    AppleAuthentication.AppleAuthenticationScope.EMAIL,
  ],
});

// Send to Supabase
const { data, error } = await supabase.auth.signInWithIdToken({
  provider: 'apple',
  token: credential.identityToken,
});
```

### Platform Handling
- iOS: Show Apple Sign In button
- Android: Hide button, email only
- Web: Not supported in MVP
