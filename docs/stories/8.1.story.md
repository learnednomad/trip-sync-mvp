### App Metadata
```
Name: Trip Sync
Subtitle: Split expenses with friends

Description:
Trip Sync makes it easy to track and split expenses during trips with friends. No more spreadsheets or confusion about who owes what!

Features:
• Create trips and invite friends
• Track expenses on the go
• Automatic fair splitting
• Works offline
• Real-time sync
• See who owes whom

Keywords:
trip, expense, split, travel, friends, costs, share, bills, group, vacation

Category: Travel (primary), Finance (secondary)
```

### EAS Build
```bash

eas build --platform all --profile production

# Submit to stores
eas submit --platform ios
eas submit --platform android
```
