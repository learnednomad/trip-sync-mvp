# Story 1.1: Basic Theme System (MVP)

## Status
Ready for Development

## Story
**As a** mobile app developer,  
**I want** a minimal theme system with light/dark mode support,  
**So that** I can build consistent UI components quickly for the MVP

## Acceptance Criteria
1. Light and dark theme configurations created
2. 4 semantic colors defined: primary, surface, background, error
3. 3 text sizes implemented: small (14px), medium (16px), large (20px)
4. Simple theme toggle functionality (no animations)
5. Theme persisted to MMKV storage
6. All colors meet basic contrast requirements

## Dev Notes

### MVP Simplifications
- NO complex color system (just 4 colors)
- NO typography scale (just 3 sizes)
- NO animations or transitions
- NO high-contrast mode
- NO platform-specific styling
- NO Tachyons/complex integration

### Technical Approach
- Use React Context for theme state
- Store preference in MMKV: `theme_preference: 'light' | 'dark'`
- Apply theme via NativeWind/Tailwind classes
- Keep it SIMPLE - this is MVP!

### File Structure
```
/src/theme/
  ├── colors.ts      # Color definitions
  ├── context.tsx    # Theme provider & hook
  └── index.ts       # Exports
```
